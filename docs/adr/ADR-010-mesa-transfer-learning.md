# ADR-010: MESA dataset for sleep staging transfer learning

## Context
The two-phase sleep stage classifier described in ADR-006 trains its Random Forest personalisation layer on heuristic labels generated by the same system it is trying to improve. Self-referential training on heuristic labels risks reinforcing systematic errors rather than correcting them: if the heuristic misclassifies certain breathing patterns as light sleep instead of deep, the model learns to reproduce that error. After enough nights the model may overfit to the individual's idiosyncrasies in a way that degrades generalisability and makes the score less interpretable.

The practical problem is that obtaining EEG-validated ground truth labels for a single person sleeping in their own bedroom is expensive and disruptive. PSG requires electrode attachment and laboratory conditions or a clinical visit. A wearable EEG headband is an option but adds contact with the body, which the system design explicitly avoids.

## Options considered

**Personal heuristic labels only.** The simplest approach: train the personalisation layer entirely on labels from the system's own heuristic classifier. No external data is needed. The limitation is that the labels the model learns from contain the same systematic errors the model is supposed to reduce. Accuracy plateaus wherever the heuristic is consistently wrong.

**Commercial wearable as supervision.** Use an Oura ring, WHOOP, or similar device to provide sleep stage labels for training. This introduces body contact, adds cost and daily behaviour change, and the wearable's own labels are population-model estimates rather than EEG ground truth. Trading one estimate for another does not solve the fundamental label quality problem.

**MESA transfer learning.** Pretrain on the MESA Sleep dataset (actigraphy features plus PSG-validated staging annotations), then fine-tune on personal nights. MESA provides EEG-validated labels for 2,056 participants at 30-second epochs. The pretrained model encodes a prior over what staging looks like based on movement and breathing features, reducing dependence on the quality of personal heuristic labels.

## Decision
MESA transfer learning, implemented as described in analysis/mesa_transfer.ipynb. Data access was approved under a Data Use Agreement with Brigham and Women's Hospital through the National Sleep Research Resource (NSRR).

## Reasoning
The feature overlap between MESA actigraphy and Basecamp CSI is substantial enough to make pretraining useful rather than decorative. MESA's activity_count corresponds to movement_power extracted from the CSI high-pass filter. MESA's zero_crossing_rate corresponds to the breathing regularity proxy derived from cross-subcarrier variance. Epoch-level context features (position within night, time since sleep onset, rolling movement statistics) are computable identically from both datasets.

The 30-second epoch size in MESA matches the 30-second window size used throughout this pipeline. This means features from MESA epochs and Basecamp windows are directly comparable without resampling or interpolation.

Published work using similar MESA-to-contactless transfer approaches reports a 5 to 8 percentage point improvement in three-class accuracy compared to training on heuristic labels alone. This is the only credible path to EEG-validated ground truth without attaching electrodes to the subject.

The MESA option was chosen over commercial wearables because PSG-validated labels are a qualitatively different signal from wearable estimates, and because the DAUA path is well-documented and approved specifically for academic research projects of this type.

## Consequences
The transfer learning notebook trains a Random Forest on MESA features and saves the pretrained weights to data/mesa_pretrained.pkl. After 30 or more personal nights have been collected, fine-tuning loads the pretrained weights and continues training on personal data. The fine-tuned model replaces the heuristic-only personalisation layer for sessions after that threshold.

Per DAUA section 8, raw MESA data files must not be committed to this repository and must be deleted within three years of project completion. Pretrained model weights derived from MESA data may be committed once generated.

Any publication or report using results from MESA-pretrained models must include the following acknowledgement: "NSRR R24 HL114473: NHLBI National Sleep Research Resource."

The notebook at analysis/mesa_transfer.ipynb runs end-to-end with synthetic stand-in data when the real MESA files are not present, so the pipeline can be reviewed and tested before data access is granted.
